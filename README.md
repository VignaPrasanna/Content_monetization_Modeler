An end-to-end data science and machine learning project that predicts potential YouTube ad revenue (ad_revenue_usd) for individual videos based on key performance metrics and contextual features. 
The project includes comprehensive exploratory data analysis (EDA), data cleaning, feature engineering, regression modeling, and an interactive Streamlit web application for real-time inference.
As video creators and media companies increasingly rely on platforms like YouTube for income, predicting potential ad revenue becomes essential for business planning and content strategy. 
This project builds and evaluates multiple regression models to estimate video earnings accurately, helping stakeholders optimize strategies and forecast future revenue.
